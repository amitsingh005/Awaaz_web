# AwaazWeb Pitch Notes & FAQ

## The Problem
90%+ of web services in India are not accessible to visually impaired citizens without extensive assistance. Traditional screen readers overwhelm users by reading hundreds of DOM tags sequentially.

## The Solution
AwaazWeb: A real-time autonomous voice-agent layer between blind users and the modern web, speaking native Hinglish and delivering concise previews first.

## Why Groq & TinyFish?
- **Groq**: Near-instant inference speed (~500+ tokens/sec) enables conversational voice loops without awkward multi-second silences.
- **TinyFish**: Purpose-built web agent infrastructure that navigates modern JavaScript SPAs, handles dynamic interactions, and bypasses screen reader hurdles.
