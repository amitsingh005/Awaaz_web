# AwaazWeb Demo Script (3-Minute Hackathon Presentation)

## Demo Scenarios
1. **Scenario 1: Read-Only Query (Information Retrieval)**
   - User: *"Delhi se Bhopal ki kal ki trains dhundho"*
   - Assistant: Searches via TinyFish, returns 3 clear numbered options with train names, timings, and fares.
2. **Scenario 2: Follow-Up & Deep Dive**
   - User: *"Doosri wali ki detail batao"*
   - Assistant: Fetches seat availability and platform info for choice 2.
3. **Scenario 3: Risky Action Safety Gate**
   - User: *"Book kar do"*
   - Assistant: Reads back the exact details and holds for explicit confirmation ("Kya main ₹1,240 ki ticket book karun? Bolen 'Haan' ya 'Nahi'").
